# PspsControl
Plataforma web para monitorear actividades de aseguramiento de calidad (SQA) de proyectos de software: proyectos por intervalo, actividades SQA, pruebas y defectos con evidencia, importación CSV, cinco indicadores con semáforo y reportes a fecha de corte. Django 5.2 + PostgreSQL. Calidad de Software · UAZ Campus Siglo XXI.
